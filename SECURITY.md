# Security Policy

## Supported Versions

Nicti is pre-v1 (see the README's Status section) — there's no tagged release yet, and no formal
support window. Security reports are welcome against the current `main` branch.

## Reporting a Vulnerability

**Please do not open a public GitHub issue for a security vulnerability.**

Report it privately through
[GitHub's private vulnerability reporting](https://github.com/jordanfelle/nicti/security/advisories/new)
for this repo. This creates a draft security advisory visible only to the maintainer and you,
where we can discuss and coordinate a fix before any public disclosure.

Include, if known:

- A description of the vulnerability and its potential impact.
- Steps to reproduce, or a proof-of-concept.
- Affected code path (file/function) if you've identified one.

You should expect an initial response within a reasonable time. Since this is an early-stage,
single-maintainer-plus-contributors project rather than a funded security team, response times
won't match a commercial vendor's SLA — but reports will be taken seriously and credited (unless
you prefer otherwise) once a fix ships.
